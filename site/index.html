UNDER THE HOOD
核心机制
每条接力路径有自己的保护边界，不将局部校验包装成全局保证。桌面端提供会话接力、接力记录、支持路径、设置四个视图，外观支持亮色、暗色与跟随系统。
01
定位来源与工作目录
根据原生会话 ID 查找记录，保留实际 cwd。不会自动把已有 Worktree 改为主仓库目录。
02
官方导入独立确认
Codex 路径绑定目标目录与配置，使用执行日志与持久锁。结果不确定时保留计划，只查询状态。
03
格式转换与降级
按目标格式转录已记录的消息与事件。不同工具保留程度不同；内部 round-trip 不等于原生继续验收。
04
转入与打开分离
导入已成功但客户端打开失败时，仅重试打开。终端启动失败会尝试复制命令，不重复转入。

$cd Watch && npm install
$npm run watch -- status --json

$npm run desktop:dev

QUESTIONS & BOUNDARIES
常见问题
Claude Code 限额或额度用完后，怎么继续手头的任务？
在 Watch 桌面端输入来源会话 ID，核对实际工作目录，选择目标 Agent。Claude → Codex 先显示官方项目先建的导入预览，明确确认后才写入，再独立打开目标会话；其他目标使用已有 CLI 适配器。Watch 不绕过限额，也不迁移代码，转入的是已有会话记录。
怎么把 Claude Code 的会话转到 Codex 继续（会话迁移 / 切换）？
两种入口：桌面端选择来源会话后点 OpenAI Codex 卡片，走官方单会话导入的 prepare → confirm → 打开；或用 CLI watch import-codex prepare <claude-id> --cwd <项目> --desktop-project --experimental，再 confirm。前提是该项目已在 Codex Desktop 中存在。工具调用记录在 Codex 侧可能变为文本，模型续写未纳入验收范围。
Claude Code 上下文满了怎么办，Watch 能压缩上下文吗？
不能。压缩或清空上下文是 Claude Code 自己的 /compact 与 /clear。Watch 做的是把已保存的会话记录整体转入另一个 Agent，目标会话从这些记录开始，原会话不变。上下文是否装得下取决于目标工具的窗口大小。
Claude Code、Codex、OpenCode 的历史对话记录在哪里，怎么恢复上次对话？
Claude Code 在 ~/.claude/projects/<按目录编码>/<会话 id>.jsonl，用 claude --resume <id> 恢复；Codex 在 ~/.codex/sessions/年/月/日/rollout-*.jsonl，用 codex resume <id>；OpenCode 在 ~/.local/share/opencode/opencode.db，用 opencode -s <id>。Watch 的「会话接力」按会话 id 反查这些位置并显示所属工作目录，「接力记录」列出同一目录的链式接力历史。
Claude Code 和 Codex 对比之后想两个都用，切换时怎么不丢上下文？
Watch 不评测哪家更好。两家都装好并认证后，用 Watch 在两者之间接力：Claude → Codex 走官方导入预览，Codex → Claude 走 CLI 适配器转换；两条路径都保留工作目录。不同格式可能降级部分事件，结果会列出降级项。
会话会经过 Watch 的云端服务器吗？
Watch 是本地会话工具，不提供自己的中继服务器。部分原生会话创建路径会调用目标 CLI，可能联网；目标 Agent 继续调用模型时，也按它自身的服务与隐私规则通信。本地转换不等于全流程离线。
可以保证无损转换或零写入风险吗？
不能。新建或整文件替换有原子写和反解校验，部分追加路径的保护范围不同。Codex 官方路径使用独立执行日志、目标锁与读后验证；完整边界见架构文档。

      
OFFICIAL ENTRY / NOT INTEGRATED
Antigravity CLI：同产品恢复与导入
官方入口已调研，Watch 接力尚未接入。以下是 Antigravity 自身的操作，不是 Watch 转换命令。
官方有依据 / Watch 未验收
01
恢复指定 CLI 会话
agy --conversation <conversation-id>
仅恢复已有的 Antigravity CLI 会话 ID，不是把 Claude、Codex 或桌面会话导入 CLI。
02
恢复当前目录最近会话
agy -c
按当前工作目录查找最近会话；记录缺失或已删除时可能新建会话。因此不能将它当作无副作用的状态探测。
03
从 Antigravity 2.0 导入
/resume
在 CLI 的会话选择器中切至 Antigravity 页签，选择桌面会话并二次确认。官方描述为克隆历史、上下文与工具轨迹；Watch 尚未原生验收，也没有外部 Agent 导入协议。
