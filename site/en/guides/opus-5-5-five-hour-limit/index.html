What Claude Opus 5.5 changes about five-hour limits, and what to do when you are still capped

Opus 5.5 raises the five-hour limit on Pro, Max, Team, and seat-based Enterprise, and adds one reset you can save. It does not remove the limit. Watch does not read or raise Claude quota. Hand the saved session to Codex only after that official reset is still not enough.

Opus 5.5 raises the five-hour usage limit on named Claude plans and adds a rate-limit reset you can save. Watch does not restore Claude quota. If you are still blocked, use the existing Codex handoff.

Published: 2026-09-23 Modified: 2026-10-14 Applies to: Watch v0.1.1
What the announcement actually changes

On 22 September 2026 Anthropic introduced Claude Opus 5.5. On limits, the announcement says two things: five-hour usage limits increase on Pro, Max, Team, and seat-based Enterprise plans, and subscription users receive a rate-limit reset they can save and spend when they choose. It does not say weekly limits were removed, and it does not say any third-party tool can refill Claude quota.

A faster or cheaper model does not merge the two limits. A full context window is still a long conversation: compact it inside Claude Code. An account usage limit still stops requests until the window resets. Opus 5.5 widens the five-hour usage window on the plans named above. It does not enlarge the context window.

  1. Step 1: Read which limit the product is reporting

    A message that you have exceeded the current usage limit, with a reset time, is an account limit. /compact does not restore that quota. A message about conversation length is a context-window limit. Compact inside Claude Code. Switching the model name is not the fix for either case.

  2. Step 2: Use the plan’s own five-hour limit and saved reset

    The higher five-hour limit applies to Pro, Max, Team, and seat-based Enterprise. The savable reset belongs to the Claude subscription. Watch has not verified a CLI flag that stores it, so do not assume a Watch command has banked the reset for you. If you are still blocked after the reset Anthropic provides, then consider another agent.

  3. Step 3: Hand off only if Claude is still blocked

    Watch does not read, raise, or bypass Claude quota. It copies a session already saved on disk into Codex, keeping the working directory. Follow the existing guide, Continuing in Codex after Claude Code reaches its usage limit: check the session id and directory, then prepare, confirm, and open Codex separately.

What a trending query does not establish

The query “opus 5.5” appeared in Singapore and Australia trending searches over 48 hours. That is an approximate trending bucket, not a global ranking of search volume, and it does not show that weekly limits, context length, or session files changed. Other model names in the same news cycle are unrelated to this handoff. Tool calls may still be degraded to text on the Codex side.

Frequently Asked Questions

Does Claude Opus 5.5 remove the five-hour usage limit?

No. Anthropic increased the five-hour limit on Pro, Max, Team, and seat-based Enterprise. The limit still exists, and hitting it still shows a reset time.

Can Watch spend the savable rate-limit reset for me?

No. That control belongs to the Claude subscription. Watch does not sign in to a Claude account, and it neither stores nor spends the reset.

Do I still hand the session to Codex after the limit increase?

Only when the official reset is not enough and Codex still has quota. The handoff steps did not change with Opus 5.5.
