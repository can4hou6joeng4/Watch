Claude Opus 5.5가 5시간 한도에서 바꾸는 것과, 여전히 막혔을 때 할 일

Opus 5.5는 Pro, Max, Team, 좌석 기반 Enterprise의 5시간 한도를 올리고, 저장할 수 있는 재설정 하나를 추가합니다. 한도를 없애지는 않습니다. Watch는 Claude 할당량을 읽거나 올리지 않습니다. 그 공식 재설정으로도 부족할 때만 저장된 세션을 Codex로 넘기세요.

Opus 5.5는 명시된 Claude 플랜의 5시간 사용 한도를 올리고, 저장할 수 있는 속도 제한 재설정을 추가합니다. Watch는 Claude 할당량을 복원하지 않습니다. 여전히 막혀 있으면 기존 Codex 핸드오프를 사용하세요.

게시: 2026-09-23 수정: 2026-10-14 적용 버전: Watch v0.1.467
공지가 실제로 바꾸는 것

2026년 9월 22일 Anthropic은 Claude Opus 5.5를 공개했습니다. 한도에 대해 공지는 두 가지를 말합니다. Pro, Max, Team, 좌석 기반 Enterprise 플랜의 5시간 사용 한도가 오르고, 구독 사용자는 원할 때 저장했다가 쓸 수 있는 속도 제한 재설정을 받습니다. 주간 한도가 제거되었다고 하지 않으며, 제3자 도구가 Claude 할당량을 다시 채울 수 있다고도 하지 않습니다.

더 빠르거나 더 저렴한 모델이 두 한도를 합치지는 않습니다. 가득 찬 컨텍스트 창은 여전히 긴 대화입니다. Claude Code 안에서 압축하세요. 계정 사용 한도는 창이 재설정될 때까지 요청을 막습니다. Opus 5.5는 위에 이름 붙인 플랜의 5시간 사용 창을 넓힙니다. 컨텍스트 창을 키우지는 않습니다.

  1. 1단계: 제품이 어떤 한도를 보고하는지 읽기

    재설정 시각과 함께 현재 사용 한도를 초과했다는 메시지는 계정 한도입니다. /compact는 그 할당량을 복원하지 않습니다. 대화 길이에 대한 메시지는 컨텍스트 창 한도입니다. Claude Code 안에서 압축하세요. 모델 이름을 바꾸는 것은 어느 경우의 해결책도 아닙니다.

  2. 2단계: 플랜 자체의 5시간 한도와 저장된 재설정 사용

    더 높은 5시간 한도는 Pro, Max, Team, 좌석 기반 Enterprise에 적용됩니다. 저장 가능한 재설정은 Claude 구독에 속합니다. Watch는 이를 저장하는 CLI 플래그를 검증하지 않았으므로, Watch 명령이 재설정을 보관해 두었다고 가정하지 마세요. Anthropic이 제공하는 재설정 후에도 막혀 있으면 그때 다른 에이전트를 고려하세요.

  3. 3단계: Claude가 여전히 막혀 있을 때만 핸드오프

    Watch는 Claude 할당량을 읽거나 올리거나 우회하지 않습니다. 디스크에 이미 저장된 세션을 작업 디렉터리를 유지한 채 Codex로 복사합니다. 기존 가이드 「Claude Code가 사용 한도에 도달한 뒤 Codex에서 계속하기」를 따르세요. 세션 id와 디렉터리를 확인한 다음 prepare, confirm하고 Codex를 따로 엽니다.

급상승 검색어가 확정하지 않는 것

검색어 “opus 5.5”는 48시간 동안 싱가포르와 호주의 급상승 검색에 나타났습니다. 이는 대략적인 급상승 구간이지 검색량의 전 세계 순위가 아니며, 주간 한도, 컨텍스트 길이, 세션 파일이 바뀌었음을 보여 주지 않습니다. 같은 뉴스 주기의 다른 모델 이름은 이 핸드오프와 무관합니다. 도구 호출은 Codex 쪽에서 여전히 텍스트로 저하될 수 있습니다.

자주 묻는 질문

Claude Opus 5.5가 5시간 사용 한도를 없애나요?

아니요. Anthropic은 Pro, Max, Team, 좌석 기반 Enterprise의 5시간 한도를 올렸습니다. 한도는 여전히 있으며, 걸리면 재설정 시각이 표시됩니다.

Watch가 저장 가능한 속도 제한 재설정을 대신 써 주나요?

아니요. 그 제어는 Claude 구독에 속합니다. Watch는 Claude 계정에 로그인하지 않으며, 재설정을 저장하거나 쓰지도 않습니다.

한도가 오른 뒤에도 세션을 Codex로 넘겨야 하나요?

공식 재설정으로도 부족하고 Codex에 아직 할당량이 있을 때만입니다. 핸드오프 단계는 Opus 5.5와 함께 바뀌지 않았습니다.
