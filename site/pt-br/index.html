UNDER THE HOOD
Mecanismos centrais
A proteção é específica de cada rota. Uma verificação estreita não é uma garantia universal de segurança. O app desktop tem quatro visões (revezamento de sessão, histórico de revezamentos, rotas suportadas, configurações) com aparência clara, escura e do sistema.
01
Localizar a origem e o cwd
Encontre registros armazenados pelo ID nativo da sessão e preserve o cwd real. Worktrees existentes não são substituídas silenciosamente pela raiz do repositório.
02
Confirmar importações oficiais
A rota do Codex vincula o diretório e a configuração de destino, com um diário de execução e um bloqueio persistente. Resultados incertos são consultados, não reenviados às cegas.
03
Expor limitações de formato
Transfira mensagens e eventos registrados para o formato de destino. A preservação varia; uma ida e volta interna não é prova de continuação nativa.
04
Separar a importação da abertura
Se a abertura falhar após a importação, tente abrir de novo apenas. Uma falha ao iniciar o terminal recai na cópia de um comando após verificar caracteres de controle, sem outra transferência.

ANSWERS FIRST
Guias
Cada guia começa com uma resposta que se sustenta sozinha e depois traz os passos. O Watch não contorna limites e não classifica modelos.
Continuar no Codex depois que o Claude Code atinge o limite de uso
Quando o Claude Code informa um limite de cinco horas ou semanal, /compact não restaura a cota. O Watch lê apenas o arquivo local ~/.claude/projects/<encoded-cwd>/<session>.jsonl, confere o diretório de trabalho e copia esse registro para o Codex. O arquivo original permanece inalterado. Eventos de ferramentas podem virar texto.
Ler o guia
Guia de revezamento bidirecional de sessão entre OpenCode, Claude e Codex
O OpenCode guarda as sessões em ~/.local/share/opencode/opencode.db. WATCH_OPENCODE_DB aponta o Watch para outro arquivo. O Watch grava sessions, messages e parts em uma única transação SQLite e faz rollback se falhar. Campos de ferramenta sem suporte viram texto. As respostas posteriores dependem do modelo que você configura.
Ler o guia
Janela de contexto cheia versus limites de uso no Claude Code: guia prático
Uma janela de contexto cheia significa que esta conversa está longa demais: execute /compact ou /clear dentro do Claude Code. Um limite de conta indica um horário de redefinição, e /compact não faz nada nesse caso. O Watch não amplia a janela nem restaura a cota. Ele copia a sessão salva para outro agente que ainda possa executar.
Ler o guia
O que o Claude Opus 5.5 muda nos limites de cinco horas e o que fazer quando você ainda está no teto
O Opus 5.5 eleva o limite de cinco horas nos planos Pro, Max, Team e Enterprise por assento, e adiciona uma redefinição que você pode guardar. Ele não remove o limite. O Watch não lê nem eleva a cota do Claude. Passe a sessão salva ao Codex somente depois que essa redefinição oficial ainda não for suficiente.
Ler o guia
Por que a retomada abre uma sessão vazia: detectar e recuperar sessões com 0 turno
Uma sessão vazia após a retomada geralmente significa que o arquivo não tem mais turnos: uma sessão vazia legítima criada por watch new, um conteúdo apagado deixando apenas um cabeçalho de espaço reservado, ou um arquivo de 0 byte. Verifique a contagem de turnos na linha da ponta da cadeia em watch status. O Watch não reconstrói o histórico por você; restaure o arquivo a partir de um backup, vincule outra sessão, ou inicie uma nova cadeia.
Ler o guia
Usar watch prompt quando não há adaptador
Quando a ferramenta de destino não tem adaptador ou seu formato nativo acabou de mudar, execute watch prompt <session-id> para montar uma transferência Markdown somente leitura. Ele não grava arquivos de sessão nem inicia nenhuma CLI; as contagens de corte e degradações ficam no documento e nos findings do --json, e o destino deve tratá-lo como resumo, não como sessão nativa.
Ler o guia
Sessões do Codex reduzidas a .jsonl.zst: limites de leitura e recuperação no Watch
Depois que o Codex comprime uma thread local, o rollout só permanece como .jsonl.zst; o Watch não lê o formato comprimido, então a sessão não aparece em nenhuma lista. Use o watch doctor para ver a contagem de não atribuíveis e continue a thread no Codex para disparar a reexpansão. Uma cópia de 0 byte perdeu o conteúdo; restaure de um backup. Não apague nem renomeie o arquivo .zst.

Executar a partir do código-fonte
Os comandos abaixo estão agrupados por CLI e por build de desktop e podem ser copiados diretamente. Execute npm install na raiz do repositório antes de rodar a partir do código-fonte; o aplicativo de desktop também precisa das dependências em desktop/. Os instaladores dependem de um Node externo na máquina do usuário.
Node ≥ 22.13 · Compilações do Desktop também exigem Rust / Tauri
$git clone https://github.com/can4hou6joeng4/Watch.git
$cd Watch && npm install
$npm run watch -- status --json
$npm run watch -- import-codex prepare <claude-id> --cwd /abs/project --desktop-project --experimental --json
$npm --prefix desktop install
$npm run desktop:dev
$cd desktop && npx tauri build
Falta o tsx? Execute npm install primeiro. Um erro de node:sqlite exige conferir a versão do Node.

QUESTIONS & BOUNDARIES
Perguntas
O Claude Code atingiu o limite no meio da tarefa. Como continuo?
Informe o ID da sessão de origem no Watch, confira o diretório de trabalho detectado e escolha um agente de destino. Claude → Codex mostra a prévia oficial de importação com o projeto primeiro e só grava depois que você confirma; em seguida abre o destino separadamente. Os outros destinos usam os adaptadores de CLI existentes. O Watch não contorna limites de uso e não move código; ele transfere o registro da sessão salva.
Como passo do Claude Code para o Codex e retomo a mesma sessão?
Dois pontos de entrada: no app desktop, selecione a sessão de origem e clique no cartão do OpenAI Codex (importação oficial de uma sessão: prepare → confirm → open) ou execute watch import-codex prepare <claude-id> --cwd <project> --desktop-project --experimental, seguido de confirm. O projeto já precisa existir no Codex Desktop. Registros de ferramentas podem virar texto no lado do Codex, e a continuação do modelo está fora do escopo validado.
A janela de contexto do meu Claude Code está cheia. O Watch a compacta?
Não. Compactar ou limpar o contexto é o próprio /compact e /clear do Claude Code. O Watch move o registro da sessão salva por inteiro para outro agente; a sessão de destino começa a partir desse registro e a sessão original permanece intacta. Se cabe ou não depende da janela de contexto da ferramenta de destino.
Onde ficam os arquivos de sessão do Claude Code, do Codex e do OpenCode, e como retomo uma conversa anterior?
Claude Code: ~/.claude/projects/<encoded-cwd>/<session-id>.jsonl, retome com claude --resume <id>. Codex: ~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl, retome com codex resume <id>. OpenCode: ~/.local/share/opencode/opencode.db, retome com opencode -s <id>. O Watch os localiza pelo ID da sessão, mostra o diretório de trabalho proprietário e lista os revezamentos encadeados desse diretório em Histórico de revezamentos.
Por que uma sessão listada por watch status abre vazia após a retomada?
resume apenas abre uma sessão existente. Uma sessão vazia geralmente não tem mais turnos: uma sessão vazia legítima criada por watch new, um conteúdo apagado deixando apenas um cabeçalho de espaço reservado, ou um arquivo de 0 byte. Verifique a contagem de turnos da ponta da cadeia em watch status; o Watch informa o motivo quando é 0. O Watch não reconstrói o histórico: restaure o arquivo a partir de um backup, vincule outra sessão com watch adopt, ou inicie uma nova cadeia com watch chain new.
O aviso do watch doctor sobre o risco de limpeza do Claude Code é certeiro?
É uma estimativa calculada a partir do horário de modificação do arquivo da ponta da cadeia e do cleanupPeriodDays definido pela precedência das configurações, não uma prova de exclusão. Ele aparece apenas para pontas de cadeia do Claude Code quando o valor explícito está abaixo do padrão oficial de 30 dias. Um valor curto sobrescrito por uma configuração de precedência maior deixa de ser relatado, e quando um arquivo de precedência maior não pode ser lido, nenhum valor menor é usado para adivinhar. Worktrees e submódulos não leem as configurações da raiz do repositório do checkout principal, então a estimativa pode ser conservadora. O valor efetivo ainda depende de todas as configurações que o Claude Code carrega; --settings e configurações gerenciadas estão fora do escopo. Faça backup do arquivo da ponta da cadeia, aumente a retenção, ou revincule com watch switch; --strict trata avisos como falhas.
Uso Claude Code e Codex. Como passo de um para o outro sem perder o contexto?
O Watch não classifica os dois. Com ambos instalados e autenticados, passe as sessões: Claude → Codex usa a prévia de importação oficial, Codex → Claude usa a conversão do adaptador de CLI; os dois mantêm o diretório de trabalho. Alguns eventos podem ser degradados entre os formatos, e o resultado lista o que foi degradado.
O histórico passa por um servidor em nuvem do Watch?
O Watch não tem um servidor de retransmissão próprio. Algumas rotas nativas de criação de sessão invocam o CLI de destino e podem acessar os serviços de rede dele. A continuação do modelo também segue as regras de privacidade e de modelo desse serviço. Conversão local não significa um fluxo totalmente offline.
A conversão é sem perdas ou sem riscos?
Não. Arquivos novos e substituições do arquivo inteiro têm gravações atômicas e verificações de releitura, enquanto alguns caminhos de acréscimo têm proteções diferentes. As importações oficiais do Codex usam o próprio diário, bloqueio de destino e verificação de releitura. Veja a arquitetura para os limites exatos.

      
OFFICIAL ENTRY / NOT INTEGRATED
Antigravity CLI: retomada e importação no mesmo produto
Pontos de entrada oficiais revisados; não integrados ao Watch. São operações do Antigravity, não comandos de conversão do Watch.
Documentado oficialmente / Não validado pelo Watch
01
Retomar uma conversa específica do CLI
agy --conversation <conversation-id>
Retoma um ID de conversa existente do Antigravity CLI. Não é um importador de conversas do Claude, do Codex ou do desktop.
02
Continuar a conversa mais recente do workspace
agy -c
Procura a conversa mais recente do diretório de trabalho atual. Um histórico ausente ou excluído pode iniciar uma nova conversa, então isto não é uma verificação de status sem efeitos colaterais.
03
Importar do Antigravity 2.0
/resume
Mude para a aba Antigravity no seletor de sessões do CLI, selecione uma conversa do desktop e confirme a importação. A documentação oficial descreve histórico clonado, contexto e trajetórias de ferramentas. O Watch não validou isso nativamente e não tem um contrato de importação de agentes externos.
