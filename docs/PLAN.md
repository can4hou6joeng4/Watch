# Watch · 产品需求与实施计划

> 更新：2026-09-10。本文替代最初的三期工作台规划；描述需求，不代表功能已交付。
> 品牌：值更 · Relieve the watch. The voyage never stalls.

## 1. 产品定义

Watch 是本地会话接力工具：让用户换一个 AI 编程工具，继续同一项工作。

支持范围以实际接力路径为单位，不以 CLI、桌面端或 IDE 划死边界。优先复用官方导入、恢复和客户端互通能力；只有来源读取、目标接收、项目定位和继续工作均通过验证，才能标记该路径可用。

Watch 不提供模型、不绕过配额、不代替原生 Agent 聊天，也不默认搬迁权限、凭据、插件或用户配置。接力的是已有记录，不是模型未记录的内部状态；不同工具的理解与可保留内容可能不同。

## 2. 用户任务与主流程

用户遇到限额、排查停滞或主动换工具时，希望保留需求、已有结论和工具执行记录，而不用重述背景。

目标流程如下；交接预览、客户端选择和完整结果报告尚需实现：

1. 粘贴来源会话 ID；后续可增加近期会话选择，减少手工寻找 ID。
2. 识别来源工具、可确认的客户端、实际工作目录及会话摘要。不凭工具名称猜测存储位置。
3. 选择目标 Agent，再选择可用客户端：桌面端、终端或仅复制恢复命令。
4. 预览交接方式、目标会话是新建还是复用、已知降级，以及是否需要停止会话或退出应用。
5. 用户确认后转入；优先官方路径，必要时使用已验证的格式转换。摘要交接必须明确标为新会话降级方案。
6. 报告目标会话与实际工作目录。打开成功与会话可继续是不同状态，不得仅以进程启动成功宣布接力成功。
7. 失败时保留已有记录；若转入已成功而客户端打开失败，只重试打开，不重复转入。

## 4. 本轮产品范围

### 必须完善

- 正确识别来源与工作目录，区分普通项目目录、已有 Worktree、远程环境；不自动将工作目录替换为仓库根。
- 记录每条路径的读取、接收和打开能力、平台、版本及未解决限制。
- 先检查官方可复用入口，再决定是否增加或替换私有格式写入；已有基础适配器基线路径不会仅因官方实验未完成而停用，交互式导入向导也不伪装成可编程接口。
- 对转换范围、丢失、合成、跳过与失败提供可见说明，保留终端和复制回退。
- 将交接准备、确认写入、打开客户端分离；异步操作绑定原始请求，避免切换来源后显示旧结果。
- 明确新建与复用策略，重复点击或重试不能盲目创建新会话或重复追加历史。
- 为写入、失败恢复和数据库迁移补足回归覆盖；原生客户端验收不能由内部 round-trip 替代。

### 暂不纳入默认任务

Worktree 自动创建、用量大盘、团队分享、云端同步、插件市场、模型自动调度、混淆商业化封装，以及继续扩充终端种类。已有功能保留，不为收紧范围删除现有代码。需要新增时重新确认价值与范围。

Claude 普通聊天、Cowork 和云端会话不等同于 Claude Code。即使某官方导入器可读取它们，也不自动纳入 Watch 的编程会话支持范围。

## 6. 首条路径的用户验收

第一条候选路径为 Claude Code 本地编程会话转入 Codex，再在已安装的桌面端继续。官方文档依据与限制见兼容性矩阵；本地手工生成 rollout 是否可用仍需实验。

- 桌面打开的是指定目标会话，而不是空白聊天或另一个历史会话。
- 若用户选择已有桌面项目，必须在导入前确认 cwd 精确匹配唯一项目；导入后同时验证官方项目筛选与 Desktop 私有排除状态。cwd 或后端 `projectId` 单独成功都不能替代 GUI 验收。
- 实际 cwd 与来源匹配；已有 Worktree 不被悄悄切换为主工作树。
- 测试记录中的需求、结论、工具调用与结果按预期呈现；不支持的内容有明确说明。
- 原生继续一轮后，新消息属于正确会话；该步骤可能调用模型，须单独授权。
- 再次交接无重复或错配；转换成功但打开失败时可仅重试打开。
- 源会话和无关目标会话保持不变；不能保证安全时拒绝写入。

## 7. 数据与权限边界

自动测试不得读取真实 Agent 历史或调用模型。原生 GUI 不一定遵从临时 `HOME`；需要测试账户或确认可隔离的客户端环境，不能假设命令行环境变量隔离了桌面端。

官方导入可能涉及聊天以外的设置。必须让用户确认选择范围；不自动导入凭据、放宽权限、开启同步，或向云端发送历史。真实样本导入、模型继续、安装升级、退出用户应用和发布分别授权。
