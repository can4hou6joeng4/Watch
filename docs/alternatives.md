Watch 从本机原生会话记录和工作目录出发，由用户发起接力。各写入路径有独立的防护措施，具体取决于走启动器、链式接力还是 Codex 官方导入。目标缺少适配器时，可用 `watch prompt` 导出只读 Markdown 摘要。`status --json` 可从切换记录回溯会话血缘，桌面接力记录显示同一份计数。桌面近期列表区分扫描中、读取失败和空列表。各路径的防护范围见[架构说明](ARCHITECTURE.md)。

[herdr-agent-handoff](https://github.com/sanirudh17/herdr-agent-handoff) 从 Herdr 的源窗格定位会话，在另一个 Agent 的新窗格交接。完整转录放不进提示词时，它提供来源路径、行范围和 SHA-256 供核对。Watch 的 `prompt` 交付 Markdown 摘要，并比较读取前后的文件大小和修改时间来提示来源有变化。

[ccompactor](https://github.com/ccompactor/ccompactor) 从 Claude Code、Codex 和 Pi 的本机记录生成带事件引用的交接包。`verify` 检查交接包的结构，并对照源转录核验引用。Watch 的 `prompt` 提供可复制的 Markdown 摘要和裁剪披露。

| Convert local records into the target's native format | [cross_agent_session_resumer](https://github.com/Dicklesworthstone/cross_agent_session_resumer) and [session-migrate](https://github.com/xhluca/session-migrate) convert native session formats. [catchup](https://github.com/wilbeibi/catchup) focuses on transcripts and also offers `fork` and `fork --into`. [ferry](https://github.com/williamfzc/ferry) is a Go library that preserves the original bytes. For cross-tool conversions it returns target-format bytes for the caller to write, reads the projection back to compare tool inputs, and lists format limitations. [session-export](https://github.com/vibheksoni/session-export) converts and searches history through an SDK, CLI and MCP server. Its CLI defaults to a dry run and requires `--write` to write output. It documents 12 providers, with T3 Code as an experimental target. [sepia](https://github.com/9aia/sepia) uses a shared session representation for Devin, Cline, Claude Code and Cursor, and its `install` command writes target sessions. [agent-session-bridge](https://github.com/bohdanpodvirnyi/agent-session-bridge) (MIT, 109★) is a local CLI that parses native sessions between Pi, Claude Code and Codex and writes directly into each tool's own session store, keeps mirror state to prevent replay loops, and offers `repair` and `audit`; its README notes that older imports may still need `repair` and that some legacy Codex imports emit orphan-output warnings during resume. [session-bridge](https://github.com/pma1999/session-bridge) (MIT, 4★) moves conversations between Claude Code, OpenCode and Codex CLI locally without calling a model: on verified target versions it creates a new session in the target's own format and never edits the source or existing sessions. Native write and sync are Windows x64 only (Linux / WSL gets manual handoff), with version gates (Claude Code 2.1.304+, OpenCode 2.0.29+ within 2.x, Codex 0.159.0+ within 0.x; older majors and OpenCode 1.x are refused) and caps of 9,362 OpenCode messages / 128 MiB Codex files; it keeps archives and a journal and bases compatibility on four observed behaviors: persistence, history listing, cold-start resume and imported context reaching the model. These descriptions come from public docs or source code. Watch has not tested native resume for these tools. [MultiCC](https://github.com/lsjwzh/MultiCC) (MIT, self-hosted) keeps tasks, sessions and Git snapshots on the task and lets the engine switch among Claude Code, Codex, OpenCode, Kimi Code, Grok, pi and more: it preserves native sessions where supported, otherwise passes a bounded visible-text checkpoint and explicitly does not claim hidden state, and resumes the original CLI's native session when switching back. [txcript](https://github.com/skillsynchq/txcript) (Apache-2.0, Rust library, CLI and WASM) converts sessions across Claude Code, Codex, OpenCode, Cursor, pi, Grok and more than a dozen tools, writes a new native session for the destination, can launch that agent, and also supports interchange JSON. [agentswap](https://github.com/bojieli/agentswap) (MIT, Go) validates and translates native sessions into new Claude Code, Codex, OpenCode or Kimi Code sessions (`teleport` / `handoff`); it can also fail over across subscriptions and quotas and resume after a reset, and never switches harnesses silently. |

Watch starts from local native session records and the working directory. The user initiates each handoff. The launcher, chained handoff and official Codex import have separate entry points and write protections. Use `watch prompt` for a read-only Markdown summary when the target lacks an adapter. `status --json` traces lineage from recorded switches, with the same counts in desktop handoff history. The desktop recent list distinguishes scanning, read failures and an empty list. See the [architecture](ARCHITECTURE.md) for the protection each route provides.

[herdr-agent-handoff](https://github.com/sanirudh17/herdr-agent-handoff) locates a session from its source pane and hands it off to a fresh agent pane in Herdr. If the full transcript exceeds the prompt budget, the plugin provides the source path, line bounds and SHA-256 for verification. Watch `prompt` produces a Markdown summary and compares file size and modification time before and after reading to flag source changes.

[ccompactor](https://github.com/ccompactor/ccompactor) creates handoff packages with event references from local Claude Code, Codex, and Pi records. Its `verify` command checks package structure and checks quotes against the source transcript. Watch `prompt` provides a Markdown summary with disclosures about trimmed content.
